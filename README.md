# Library Desk

Small React + Express app used as a pairing exercise. See [TASK.md](TASK.md).

```
server/   Express API (in-memory data)
src/      React app (Vite)
```

```bash
git clone https://github.com/irfanmahamud/library-desk-interview-boilerplate.git
cd library-desk-interview-boilerplate
npm install
npm run dev     # API on :3001, web on :5173
```
